# Public Ride Share MVP – PRD

## Problem
People commuting to work often drive alone. Others want a cheap way to get to the same area. Matching them can reduce traffic, save money, and help the environment.

## Goal
Let riders (drivers) offer rides, and passengers request a ride if they're going in the same direction. The app should match them based on location, destination, and walking distance.

## User Roles
- **Rider**: Going to a destination, willing to pick someone up on their route.
- **Passenger**: Needs a ride and is willing to walk a bit to meet the rider.

## Core Features for MVP
1. Rider can:
   - Set destination.
   - Share live location.
   - Offer a ride.

2. Passenger can:
   - Set pickup and destination.
   - Set how far they're willing to walk.
   - Request a ride.
   - See matching riders.

3. The system:
   - Matches passenger to a nearby rider going the same direction.
   - Considers walking distance and rider path overlap.
   - Notifies both when a match is made.

## Out of Scope (for now)
- Payments.
- Ratings or reviews.
- Scheduled rides beyond 1 hour ahead.
- Detour logic.

## Success Metric
Can a passenger find a rider going the same direction and walk to join within 5–10 minutes?
